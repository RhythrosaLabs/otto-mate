# Otto Test Outputs

This directory contains outputs from Otto's autonomous workflows and tests.

## Structure

- **images/** - AI-generated images, designs, mockups
- **videos/** - Generated video content, ads, animations
- **text/** - Blog posts, product descriptions, marketing copy
- **products/** - Product creation logs and metadata

## Usage

Run tests with: `./test_comprehensive.sh`

Each test creates a timestamped subdirectory with all artifacts.
