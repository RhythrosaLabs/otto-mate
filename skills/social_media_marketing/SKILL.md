# Social Media Marketing Skill

## Description
Complete social media marketing automation including content creation, scheduling, engagement, and analytics across multiple platforms.

## Capabilities
- **Content Generation**: Create platform-specific posts
- **Campaign Management**: Plan and execute marketing campaigns
- **Engagement Automation**: Automated responses and interactions
- **Hashtag Research**: Find trending and niche hashtags
- **Competitor Analysis**: Monitor competitor social media
- **Performance Analytics**: Track engagement and conversions

## Workflows

### Product Launch Campaign
```yaml
name: Social Media Product Launch
steps:
  1. Analyze product and target audience
  2. Research trending hashtags in niche
  3. Create campaign strategy (content calendar)
  4. Generate post copy for all platforms:
     - Instagram: Visual-focused, hashtags
     - Facebook: Community-focused, longer copy
     - Twitter/X: Concise, trending topics
     - TikTok: Video script concepts
     - Pinterest: SEO-optimized descriptions
  5. Create accompanying visuals
  6. Schedule posts with optimal timing
  7. Set up engagement monitoring

success_criteria:
  - 7-14 posts created across platforms
  - Platform-optimized content
  - Visual assets included
  - Hashtag strategy defined
  - Call-to-action in each post
```

### Daily Content Automation
```yaml
name: Automated Daily Posting
steps:
  1. Check trending topics in niche
  2. Generate relevant content piece
  3. Create accompanying image
  4. Optimize for platform
  5. Post to social media
  6. Monitor early engagement
  7. Respond to comments

success_criteria:
  - Post published on schedule
  - Relevant to audience
  - Professional quality
  - Engagement within 1 hour
```

### Competitor Campaign Analysis
```yaml
name: Analyze Competitor Social Strategy
steps:
  1. Identify top competitors
  2. Analyze their recent posts
  3. Track engagement rates
  4. Identify successful content types
  5. Extract winning formulas
  6. Generate improved versions
  7. Create competitive strategy report

success_criteria:
  - Comprehensive competitor data
  - Engagement benchmarks identified
  - Content gaps discovered
  - Actionable recommendations
```

## Platform-Specific Strategies

### Instagram
- **Post Frequency**: 1-2x daily
- **Best Times**: 11am-1pm, 7pm-9pm
- **Content Mix**: 60% promotional, 30% engaging, 10% educational
- **Hashtags**: 10-20 relevant, mix of popular and niche
- **Features**: Stories, Reels, carousel posts

### Facebook
- **Post Frequency**: 1x daily
- **Best Times**: 1pm-3pm weekdays
- **Content Mix**: Community-focused, longer form
- **Features**: Groups, events, marketplace integration

### Twitter/X
- **Post Frequency**: 3-5x daily
- **Best Times**: 9am-3pm weekdays
- **Content Mix**: News, engagement, promotional
- **Features**: Threads, polls, spaces

### TikTok
- **Post Frequency**: 1-3x daily
- **Best Times**: 6am-9am, 6pm-9pm
- **Content Mix**: Entertainment-first, subtle promotion
- **Features**: Trends, challenges, duets

### Pinterest
- **Post Frequency**: 5-10x daily (high volume)
- **Best Times**: 8pm-11pm weekends
- **Content Mix**: Inspirational, instructional
- **Features**: Rich pins, idea pins, boards

## Engagement Strategies

### Response Automation
- Monitor mentions and DMs
- Auto-respond to common questions
- Escalate complex issues
- Thank customers for positive feedback
- Address complaints promptly

### Community Building
- Host Q&A sessions
- Run contests and giveaways
- Share user content
- Create exclusive groups
- Respond to comments within 1 hour

## Error Handling

### Post Rejection
- Check platform content policies
- Remove flagged keywords
- Resize images if needed
- Retry with modified content

### Low Engagement
- Analyze post timing
- A/B test different copy
- Improve visual quality
- Add call-to-action
- Boost with paid promotion

### Negative Comments
- Respond professionally
- Move to DMs for resolution
- Never delete (unless spam/abuse)
- Turn into learning opportunity

## Best Practices
- Always include a call-to-action
- Use high-quality visuals
- Post at optimal times for audience
- Engage within 1 hour of posting
- Mix promotional and value content
- Track what works and iterate
- Stay consistent with brand voice
- Use analytics to inform strategy
- Respond to ALL comments
- Cross-promote between platforms

## Analytics Tracking
- **Key Metrics**: Engagement rate, reach, clicks, conversions
- **Goals**: Set specific KPIs per platform
- **Reporting**: Weekly performance summaries
- **Optimization**: Adjust strategy based on data
