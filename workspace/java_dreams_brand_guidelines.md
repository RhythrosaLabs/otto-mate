# Java Dreams Coffee Shop - Logo Brand Guidelines

## Logo Designs
- Primary logo: Clean, modern design with coffee cup icon
- Alternative logo: Coffee bean circular pattern design

## Usage Guidelines
- Minimum size: 1 inch width for print, 120px for digital
- Clear space: Maintain space equal to the height of the text around logo
- Colors: Warm browns, creams, and earth tones
- Background: Works on white, cream, or light backgrounds

## Applications
- Storefront signage
- Business cards
- Coffee cups and packaging
- Social media profiles
- Website header

## File Formats
- PNG with transparent background for digital use
- Vector format recommended for print and scaling
